# 📊 HR Analytics Dashboard

## 📌 Project Overview

This is an End-to-End HR Analytics Project developed using Excel, SQL, Power BI, and DAX. The dashboard helps HR teams analyze workforce data, monitor employee performance, understand attrition, and support data-driven decision-making.

---

## 🛠 Tools Used

- Microsoft Excel
- MySQL
- Power BI
- DAX

---

## 📂 Dataset

- Total Employees: 1000
- Domain: Human Resources
- Format: CSV

---

## 📈 Dashboard KPIs

- Total Employees
- Average Salary
- Average Attendance
- Average Performance Rating

---

## 📊 Dashboard Visualizations

- Employee Count by Department
- Average Salary by Department
- Gender Distribution
- Work Mode Analysis
- Employment Type Analysis
- Qualification Distribution
- Employee Distribution by Job Level
- Employee Count by Job Role
- State-wise Employee Count
- Attrition by Department

---

## 🗄 SQL Concepts Used

- SELECT
- WHERE
- ORDER BY
- GROUP BY
- HAVING
- CASE WHEN
- JOINS
- CTE
- Subqueries
- Window Functions
- Aggregate Functions

---

## 📊 DAX Measures Used

- COUNTROWS()
- CALCULATE()
- SUM()
- AVERAGE()
- DIVIDE()

---

## 💼 Business Questions Solved

- How many employees are in the organization?
- Which department has the highest employee count?
- Which department has the highest average salary?
- What is the gender distribution?
- What is the work mode distribution?
- Which department has the highest attrition?
